    Linear Quadratic Regulator (LQR) Control

    Overview

    Linear Quadratic Regulator (LQR) control is the advanced control technique we're implementing on our jet vanes rocket. Unlike PID control, which uses simple error-based feedback, LQR is an optimal control method that mathematically determines the best possible control law for a given system. It represents the pinnacle of classical control theory and is widely used in aerospace, robotics, and advanced industrial applications.

    Why LQR for Jet Vanes?

    Our Evolution: We successfully used PID for gimbal control, but jet vanes demand better performance:

    • Multi-variable System: Jet vanes require coordinated control of multiple surfaces
    • Optimal Performance: LQR mathematically guarantees the best possible performance for given design criteria
    • Full State Feedback: Uses all available system information, not just error
    • Systematic Design: Replaces intuitive PID tuning with rigorous mathematical optimization
    • Robustness: Better handling of uncertainties and disturbances

    Industry Standard: LQR is the foundation of modern spacecraft attitude control, aircraft autopilots, and advanced robotic systems.

    🎯 LQR Fundamentals

    The Optimal Control Problem

    LQR solves this question: "What control input minimizes a mathematical cost function while satisfying system dynamics?"

    System Model (State-Space)

    ẋ = Ax + Bu    (System dynamics)
y = Cx + Du    (Measurement equation)

    Where: - x: State vector (positions, velocities, angles, angular rates) - u: Control input vector (jet vane deflections) - A, B, C, D: System matrices describing dynamics

    Cost Function

    J = ∫₀^∞ (x'Qx + u'Ru) dt

    Where: - Q: State weighting matrix (how much you care about each state) - R: Control weighting matrix (how much you care about control effort) - J: Total cost to minimize

    Optimal Control Law

    The LQR solution is always linear state feedback: 

    u = -Kx

    Where K is the optimal gain matrix computed by solving the Riccati equation.

    Physical Interpretation

    Q Matrix: "How much do I care about each state?" - Large Q values → tight control of those states - Small Q values → relaxed control, allow more deviation

    R Matrix: "How expensive is control effort?" - Large R → gentle, conservative control - Small R → aggressive, high-energy control

    K Matrix: The optimal compromise between performance and control effort - Automatically balances Q and R requirements - Provides mathematically optimal feedback gains

    🚀 LQR for Rocket Control

    Jet Vanes System Model

    For our rocket, the state vector typically includes: 

    x = [θ, φ, ψ, p, q, r, x, y, z, u, v, w]'

    Where: - θ, φ, ψ: Euler angles (pitch, roll, yaw) - p, q, r: Angular rates - x, y, z: Position - u, v, w: Velocities

    Control inputs: 

    u = [δ₁, δ₂, δ₃, δ₄]'
    Where δᵢ are the four jet vane deflection angles.

    Design Process

    Step 1: System Linearization

    • Start with nonlinear rocket dynamics
    • Find trim points (equilibrium conditions)
    • Linearize around trim points using Jacobians
    • Results in linear state-space model: ẋ = Ax + Bu

    Step 2: LQR Weight Selection

    Q Matrix Design (State Penalties): - Attitude errors: High weights for tight pointing control - Position errors: Medium weights for trajectory following - Rate errors: Moderate weights to prevent excessive motion

    R Matrix Design (Control Penalties): - Balance control authority vs. actuator wear - Consider power consumption and actuator limits - Prevent chattering and high-frequency commands

    Step 3: Gain Computation

    • Solve Algebraic Riccati Equation (ARE)
    • MATLAB: K = lqr(A, B, Q, R)
    • Verify closed-loop stability
    • Check performance through simulation

    Step 4: Implementation Considerations

    • Handle actuator saturation
    • Account for sensor noise and delays
    • Implement gain scheduling for different flight phases
    • Add integral action if needed for disturbance rejection

    🔬 Advanced LQR Concepts

    LQR with Integral Action (LQI)

    Problem: Pure LQR has no steady-state error rejection for constant disturbances

    Solution: Augment system with integrator states 

    x_aug = [x; ∫e dt]

    Result: LQI combines LQR optimality with integral action

    Gain Scheduling

    Problem: Rocket dynamics change dramatically during flight

    Solution: Design multiple LQR controllers for different flight conditions - Hover phase: Different A, B matrices - Ascent phase: Different linearization point - Transition smoothly between controllers

    Robust LQR

    Problem: Model uncertainties can degrade performance

    Extensions: - H∞ control for worst-case robustness - μ-synthesis for structured uncertainties - Adaptive LQR for parameter variations

    🎨 LQR Design Philosophy

    The Art of Weight Selection

    Q Matrix Guidelines: - Start with identity, then iterate - Higher values → tighter control of those states - Balance different units (angles vs. positions vs. rates) - Consider coupled effects between states

    R Matrix Guidelines: - Start with identity scaled by actuator limits - Higher values → more conservative control - Balance multiple actuators appropriately - Consider actuator bandwidth and power limits

    Iterative Design Process: 1. Start with reasonable initial weights 2. Simulate closed-loop performance 3. Identify performance shortcomings 4. Adjust weights systematically 5. Re-simulate and evaluate 6. Repeat until satisfied

    Engineering Judgment

    LQR is mathematically optimal, but optimality depends on your choices: - Model accuracy: LQR is only as good as your linear model - Weight selection: No automatic way to choose Q and R - Implementation constraints: Real systems have limits LQR doesn't know about

    🚨 Common Pitfalls and Solutions

    Pitfall 1: Poor Weight Selection

    Problem: Unrealistic Q and R matrices lead to poor performance Symptoms: Oscillatory response, excessive control effort, poor tracking Solution: Use physical insight, start simple, iterate systematically

    Pitfall 2: Uncontrollable System

    Problem: Trying to control states that can't be controlled Symptoms: LQR computation fails or gives infinite gains Solution: Check controllability matrix, redesign system if needed

    Pitfall 3: Ignoring Implementation Limits

    Problem: LQR assumes unlimited control authority Symptoms: Actuator saturation, performance degradation Solution: Include actuator models, use anti-windup, consider MPC

    Pitfall 4: Over-Reliance on Linearity

    Problem: Real rockets are highly nonlinear Symptoms: Performance degrades away from trim point Solution: Use gain scheduling, adaptive control, or nonlinear methods

    Pitfall 5: Ignoring Sensor Limitations

    Problem: LQR assumes perfect state measurement Symptoms: Noise amplification, poor practical performance Solution: Combine with state estimation (Kalman filter), filter derivatives

    💡 Final Thoughts

    LQR represents a quantum leap from classical control methods like PID. It transforms control design from an art based on intuition to a science based on optimization. For our jet vanes rocket, LQR provides the mathematical rigor needed to achieve precision control in a challenging environment.

    The journey from PID to LQR parallels the evolution of engineering itself - from empirical methods to mathematical optimization. Master LQR, and you'll have a powerful tool for any advanced control challenge you encounter in your career.
