    Environment Class Documentation

    The Environment class provides a simple model of atmospheric wind profiles as a function of altitude. It uses an autoregressive (AR(1)) process to generate a wind-speed vector, capturing stochastic variability with user-defined parameters. Although focused on wind speed, the class can be extended to include other environmental effects.

    Class Overview

    classdef Environment
    ...
end
    • Inheritance: Standard MATLAB class (not a handle class); passed by value unless implemented otherwise.
    • Purpose: Provides wind-speed values at different altitudes for rocket simulations, with configurable mean, 3σ deviation, and max altitude.

    Properties

    • vm_mean (double)
      Default: 0 m/s
      Mean wind speed used in the AR(1) process.

    • vm_3sigma (double)
      Default: 15 m/s
      Three-sigma wind speed variation (used to compute AR(1) noise).

    • alts (vector)
      Altitude grid from 0 to max_altitude in step_size increments.

    • wind_vec (vector)
      Wind speed profile generated by AR(1) process at each altitude.

    • step_size (double)
      Default: 1 meter
      Step size for discretizing the altitude range.

    • max_altitude (double)
      Default: 10,000 meters
      Maximum modeled altitude for wind data.

    Methods

    Environment (Constructor)

    function obj = Environment()
    ...
end
    • Description:
    • Initializes wind model with default values.
    • Calls get_AR1() to generate wind_vec over alts.
    • Uses:
      • alpha = 0.9999
      • sigma = (vm_3sigma / 3) * sqrt(1 - alpha^2)
      • First value of wind_vec is vm_mean, rest follow AR(1).

    get_windspeed

    function windspeed = get_windspeed(obj, alt)
    ...
end
    • Inputs:
    • alt (double): Altitude in meters
    • Output:
    • windspeed (double): Wind at that altitude
    • Description:
    • Converts alt to index using step_size
    • Clamps to valid range [1, max length]
    • Returns corresponding value from wind_vec

    get_vm_mean

    function vm_mean = get_vm_mean(obj)
    ...
end
    • Description: Returns the current mean wind speed.

    get_vm_3sigma

    function vm_3sigma = get_vm_3sigma(obj)
    ...
end
    • Description: Returns the current 3σ wind value.

    set_vm_mean

    function obj = set_vm_mean(obj, vm_mean)
    ...
end
    • Description: Sets a new mean wind speed.
    • Note: You must manually regenerate wind_vec afterward.

    set_vm_3sigma

    function obj = set_vm_3sigma(obj, vm_3sigma)
    ...
end
    • Description: Sets a new 3σ wind value.
    • Note: Requires re-generating wind_vec to apply changes.

    get_altitudes

    function alts = get_altitudes(obj)
    ...
end
    • Description: Returns the altitude vector.

    set_max_altitude

    function obj = set_max_altitude(obj, altitude)
    ...
end
    • Description: Sets a new max altitude.
    • Note: You should regenerate wind_vec and alts afterward.

    get_AR1 (local/private)

    function [alt_vec, wind_vec] = get_AR1(mu, sigma, alpha, max_altitude, step_size)
    ...
end
    • Description:
    • Local method that creates AR(1) wind data:
      • $w_k = \alpha w_{k-1} + \epsilon_k$
      • $\epsilon_k \sim \mathcal{N}(0, \sigma^2)$
    • Returns altitude vector and wind vector.

    Typical Usage Workflow

    % Instantiate environment
envObj = Environment();

% Query wind at specific altitude
windSpeed = envObj.get_windspeed(500);
fprintf('Wind at 500 m: %.2f m/s\n', windSpeed);

% Get underlying properties
alts = envObj.get_altitudes();
mu = envObj.get_vm_mean();
sigma = envObj.get_vm_3sigma();

% Adjust parameters (optional)
envObj.set_vm_mean(5);
envObj.set_vm_3sigma(12);
envObj.set_max_altitude(2000);
% You must regenerate wind_vec manually if you change these

    Conclusion

    The Environment class is a lightweight tool for adding realistic wind conditions to rocket flight simulations. It uses an AR(1) process to create a smooth, stochastic wind profile from ground level up to a configurable altitude. With tunable parameters like mean and 3σ wind speed, this class provides flexible and reproducible wind data for dynamic simulations.
