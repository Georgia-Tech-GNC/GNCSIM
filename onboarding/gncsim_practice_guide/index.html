    GNCSIM Practice Guide

    Overview

    Welcome to GNCSIM! This guide will walk you through your first hands-on experience with our rocket simulation system. You'll learn how to run the Jet Vanes Rocket (JVR) simulation, modify parameters, and submit your first practice pull request.

    Learning Objectives:

    • Understand the GNCSIM simulation workflow
    • Run the JVR master file successfully
    • Modify simulation parameters and observe effects
    • Practice our Git workflow with a pull request

    📋 Prerequisites

    Before starting this practice task, make sure you've completed:

    1. Git Setup Guide - Git installation and SSH keys
    2. Git Usage Guide - Understanding basic Git workflow
    3. MATLAB Onboarding - MATLAB setup and basics

    🚀 Getting Started with GNCSIM

    What is GNCSIM?

    GNCSIM is our Guidance, Navigation, and Control Simulation system for rocket flight analysis. It simulates:

    • Rocket dynamics (mass properties, thrust curves, aerodynamics)
    • Environmental conditions (wind, atmosphere)
    • Control systems (PID/LQR controllers, jet vanes)
    • Monte Carlo analysis (uncertainty quantification)

    Key Components

    The simulation consists of several main objects:

    • Rocket: Mass properties, geometry, thrust curve
    • Aerodynamics: Forces and moments acting on rocket
    • Environment: Atmospheric conditions, wind
    • Flight: Simulation settings, initial conditions
    • TrimPoints: Linearized models for control design
    • MonteCarlo: Uncertainty analysis

    🎯 Your Practice Task

    Step 1: Create Your Practice Branch

    Follow our standard Git workflow:

    # 1. Fetch latest changes
git fetch origin

# 2. Make sure you're on main
git checkout main
git pull origin main

# 3. Create your practice branch
git checkout -b practice/your-name-introduction

# 4. Push your new branch to remote
git push origin --set-upstream practice/your-name-introduction

    Step 2: Understanding the JVR Master File

    Navigate to src/jetVanes_MasterFile.m and review the structure:

    %% Initialize Simulation
[Doof, doof_params] = setupRocket();           % Rocket parameters
[AeroObj, aero_forces_moments] = setupAerodynamics(); % Aero model
EnvironmentObj = setupEnvironment();            % Atmospheric conditions
FlightObj = setupFlight();                     % Simulation settings
TrimPointsObj = generateTrimPoints(...);       % Linear models

%% Run Flight
FlightObj.set_runClosedLoop(true);
log = FlightObj.runFlight(Doof, EnvironmentObj, AeroObj, TrimPointsObj);
FlightObj.plot_sim_dashboard(log, Doof, EnvironmentObj);

%% Run Monte Carlo (Optional, might take a while depending on number of runs)
MonteCarloObj = setupMonteCarlo(...);
logMonteCarlo = MonteCarloObj.runMonteCarlo(...);

    Step 3: Run the Base Simulation

    1. Open MATLAB and navigate to the GNCSIM/src directory

    2. Run the simulation:

    3. Navigate to the jetVanes_MasterFile.m

    4. Run the clear section, the initialize simulation, and the run flight sections one after the other (right click -> run section)

    Expected Results:

    • Simulation dashboard plots showing rocket trajectory
    • Flight data logged to console
    • No errors (if you get errors, ask for help!)

    ⚠️ Important Notes:

    • Runs might take up to ~350s

    Step 4: Explore and Modify Parameters

    Now experiment with different parameters to see their effects:

    Experiment 1: Rocket Mass Properties

    In setupRocket() function, try modifying:

    % Original values
wet_mass = 40.912994; % kg

% Try a heavier rocket:
wet_mass = 50.0;  % Heavier rocket

    Questions to explore:

    • How does increased mass affect maximum altitude?
    • Does the rocket trajectory change significantly?

    Experiment 2: Increase Wind Strength First

    In setupEnvironment() function, increase wind conditions:

    % Original values
EnvironmentObj.set_vm_mean(0.01) % m/s
EnvironmentObj.set_vm_3sigma(0.01) % m/s

% Try much windier conditions:
EnvironmentObj.set_vm_mean(10.0)   % 10 m/s mean wind
EnvironmentObj.set_vm_3sigma(15.0) % Higher wind variability

    Run the simulation again (dont' forget to inialize again) to see how the control system handles strong wind.

    Experiment 3: Turn Off Control System with Strong Wind

    Now turn off the control system but keep the strong wind in the %% Run Flight section:

    %% Run Flight
FlightObj.set_runClosedLoop(false); % Turn OFF control system
FlightObj.set_applyWind(true);      % Keep wind ON
log = FlightObj.runFlight(Doof, EnvironmentObj, AeroObj, TrimPointsObj);
FlightObj.plot_sim_dashboard(log, Doof, EnvironmentObj);

    Questions to explore:

    • How well does the control system handle strong wind?
    • What happens to the rocket when there's no control system but strong wind?
    • How much does the rocket deviate from its intended path without control?

    Step 5: Commit Your Changes

# Commit with a descriptive message
git commit -m "Practice"

    # Push your branch
git push

    🔍 Understanding Your Results

    Common Observations

    Mass Changes:

    • Heavier rockets typically reach lower altitudes
    • Mass affects acceleration and overall flight performance

    Control System Effects:

    • Without control, rockets are much more sensitive to disturbances
    • Wind can cause significant trajectory deviations in uncontrolled flight

    Wind Effects:

    • Strong winds dramatically affect rocket trajectory when controls are disabled
    • Demonstrates the importance of active control systems for stable flight

    Troubleshooting

    Common Issues:

    1. "Variable not defined" errors

    2. Make sure you're in the right directory

    3. Check that all paths are set correctly

    4. Simulation crashes

    5. Try smaller time steps

    6. Check for extreme parameter values

    7. Simulation takes forever

    8. First run generates trim points (be patient!)

    9. Subsequent runs should be faster
