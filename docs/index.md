# Welcome to GNCSIM Wiki

**Guidance, Navigation, and Control Simulation for Rocket Systems**

---

## About GNCSIM

GNCSIM is a comprehensive simulation framework designed for rocket guidance, navigation, and control systems development. This wiki serves as your complete resource for understanding, implementing, and contributing to the GNCSIM project.

## Getting Started

- Complete the [onboarding](https://gatech.enterprise.slack.com/docs/TA67E45SL/F08PS2WNE9L) steps if you are new to the team.
- Review the documentation sections below to understand the system architecture
- Join our development workflow and contribute to GNCSIM

## Project Overview

GNCSIM provides a modular approach to rocket simulation, allowing engineers to:

- Simulate various flight scenarios and environmental conditions
- Optimize control algorithms through closed-loop non linear simulations
- Analyze system performance with Monte Carlo methods
- Validate designs before hardware implementation

## Contributing

We welcome contributions from all team members!

Make sure you are fully [onboarded](#getting-started) to get your development environment set up and start contributing.

Once an issue has been assigned to you in the [GNCSIM Project](https://github.gatech.edu/orgs/gnc/projects/4), create your own branch from main, name it using the convention [Initials]_[feature] (ex: KC_navigation_fix), or just [feature] if multiple people are involved in it. 

Once all your changes are ready and working, you can submit a pull request (PR) from your branch on main. Your PR will get reviewed by the controls lead or relevant team members, and when approved, your changes will be merged on main for everyone to use.
